# ⛏ Minecraft SkinHub — Маркетплейс и блог по скинам Minecraft

Полнофункциональный локальный веб-сайт (маркетплейс и блог по скинам Minecraft) на стеке **Node.js + Express + EJS + SQLite + Multer**.

Сайт выполнен в стильном тёмном геймерском дизайне Minecraft с неоновыми зелеными (`#22c55e`), фиолетовыми (`#a855f7`) и лазурными акцентами, карточками со стеклянным размытием и адаптивной версткой.

---

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск веб-сервера
```bash
npm start
```
или:
```bash
node server.js
```

Сервер автоматически:
1. Создаст базу данных `database.sqlite` со всеми таблицами.
2. Автоматически создаст аккаунт администратора:
   - **Логин:** `admin`
   - **Пароль:** `admin`
   - **Баланс:** `5000` монет
3. Добавит стартовые скины, кейсы и публикации блога.
4. Создаст папки для загрузки пользовательских файлов в `public/uploads/`.
5. Запустит сайт на **[http://localhost:3000](http://localhost:3000)**.

## 🎮 Ключевой функционал

1. **Каталог скинов (`/skins`)**:
   - Поиск по названию скина и фильтр цен (сначала новые, дешевле, дороже).
   - Если скин не куплен — кнопка «Купить за X 🟢».
   - Если скин уже куплен — кнопка «📥 Скачать .png» для мгновенной загрузки в лаунчер.

2. **Интерактивные кейсы (`/cases`)**:
   - Анимированная рулетка с бегущей лентой скинов и звуковыми эффектами при вращении.
   - Выпавший скин моментально зачисляется в профиль игрока и доступен для скачивания.

3. **Блог и гайды (`/blog`)**:
   - Поддержка вложений: изображения, встроенный HTML5 видеоплеер и ссылки на скачивание файлов/документов (например, текстовых инструкций).

4. **Личный кабинет (`/profile`)**:
   - Текущий баланс и кнопка быстрого тестового пополнения (`+500 монет`).
   - Раздел «Мои скины» с прямым скачиванием файлов.
   - Подробная история покупок и открытий кейсов.

5. **Панель администратора (`/admin`)**:
   - Сводная статистика проекта (пользователи, скины, кейсы, посты, покупки).
   - Формы добавления скинов, кейсов и постов блога с загрузкой файлов через Multer.
   - Быстрое удаление любых материалов в один клик.
